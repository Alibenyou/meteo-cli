+++++++Application Meteo en ligne de commande++++++

comment ca fonctionne ?

C'est une application ou l'utilisateur entre en ligne de commande le nom de la ville et ensuite le programme fait un appel api gratuit et qui permet de recuperer l'altitude, la longitude et ensuite la temperateur et autre...

Mais avant de lancer l'application installer d'abord requests en utilisant cette commende : *pip install requests* puis lancer avec cette commande *python meteo.py*
